## 📌 Project Summary

This project is a simple HTTP-based Todo API built using Node.js without Express or any frameworks. It supports full CRUD operations, stores data in a JSON file, and logs every API request using the `events` module.

## ✅ Features

- Full CRUD: Create, Read, Update, Delete todos
- JSON-based data storage (`todos.json`)
- Logs all requests to `logs.txt`
- Filters todos by completion status (`GET /todos?completed=true`)
- Robust error handling
